BetterPaste

Versão 1.0.0 — PowerSpecial

Utilitário de produtividade de colagem inteligente para Windows. Inspirado no Colar Especial do Microsoft Excel e no estilo de utilitários rápidos como PowerToys Run e Funil Comercial.

⚡ Colagem Direta Restaura o foco e cola instantaneamente no app alvo via Windows API
🛠 Scripting Multi-Linguagem Suporte nativo a JavaScript, Python e VBScript
⌨ Atalhos Flexíveis Hotkeys customizáveis integradas ao System Tray
